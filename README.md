# Лабораторная работа 1: «Классы» - Реализация объектной модели данных и unit-тестов
## Описание предметной области

Реализована объектная модель для библиотеки, включающая три основных сущности:

- **Книги** (`Book`) — 11 экземпляров различных жанров, включая художественную, научную, образовательную и техническую литературу;
- **Читатели** (`Reader`) — 10 студентов;
- **Записи о выдаче книг** (`LoanRecord`) — 12 фактов взятия книг читателями, включая дату выдачи и срок аренды.

## Выполненные задачи

### 1. Объектная модель данных
Реализованы три основных класса:
- `Book` — содержит метаданные книги: инвентраный номер, автор*, название, код, издатель и тип издания.
- `Reader` — хранит персональные данные читателя: ФИО, адрес, телефон, дату регистрации.
- `LoanRecord` — фиксирует факт выдачи книги, включая связь с читателем, дату и срок займа.

Использованы типы-перечисления:
- `Publisher` — список издательств (например, Eksmo, AST, Binom).
- `PublisherType` — категоризация изданий: `Educational`, `Commercial`, `Academic`.

### 2. Подготовка тестовых данных
Создан класс `FixtureDataClass`, предоставляющий набор данных для тестирования:
- 11 различных книг;
- 10 читателей — студентов с полными ФИО, контактами и датами регистрации.
- 12 записей о выдаче книг, распределённых за период с января по апрель 2025 года.

### 3. Unit-тесты
Реализовано 5 unit-тестов с использованием LINQ для проверки бизнес-запросов:

| Тест | Описание |
|------|---------|
| `GetBorrowedBooks` | Возвращает список всех выданных книг, упорядоченных по названию. |
| `GetMostActiveReaders` | Находит топ 5 читателей, прочитавших больше всего книг за заданный период. |
| `GetReadersWithLongetsLoan` | Определяет читателей,  бравших книги на наибольший период времени, упорядоченных по ФИО. |
| `GetMostPopularPublisher` | Выводит топ 5 наиболее популярных издательств за последний год. |
| `GetLeastPopularPublisher` | Находит топ 5 наименее популярных издательств за последний год. |


## Результат


Разработана полноценная объектная модель предметной области «Библиотека» с комплексом unit-тестов, покрывающих ключевые бизнес-сценарии.
