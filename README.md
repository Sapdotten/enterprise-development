# Лабораторная работа 5: «ORM» - Интеграция клиентского приложения с оркестратором

Реализована объектная модель для библиотеки, включающая три основных сущности:

- **Книги** (`Book`) — 11 экземпляров различных жанров, включая художественную, научную, образовательную и техническую литературу;
- **Читатели** (`Reader`) — 10 студентов;
- **Записи о выдаче книг** (`LoanRecord`) — 12 фактов взятия книг читателями, включая дату выдачи и срок аренды.

## Структура решения

### 1. `Library.Domain` - описание предметной области
#### Entities
Реализованы три основных класса:
- `Book` — содержит метаданные книги: инвентраный номер, автор*, название, код, издатель и тип издания.
- `Reader` — хранит персональные данные читателя: ФИО, адрес, телефон, дату регистрации.
- `LoanRecord` — фиксирует факт выдачи книги, включая связь с читателем, дату и срок займа.

#### Enums
Использованы типы-перечисления:
- `Publisher` — список издательств (например, Eksmo, AST, Binom).
- `PublisherType` — категоризация изданий: `Educational`, `Commercial`, `Academic`.

#### Interfaces
Интерфейс для репозиториев сущностей `IRepository` определяет контракт для доступа к данным, включает в себя объяваление следующих методов:
- `Create` - создание сущности
- `Update` - обновление сущности
- `Delete` - удаление сущности
- `ReadAll` - получение списка всех сущностей
- `Read` - получение конкретной сущности

#### Data
Здесь в классе `SeedData` предопределены тестовые данные.
Данные содержат:
- 11 различных книг;
- 10 читателей — студентов с полными ФИО, контактами и датами регистрации.
- 12 записей о выдаче книг, распределённых за период с января по апрель 2025 года.

### 2. `Library.Infrastructure.InMemory` - реализация репозиториев для работы с данными, хранящимися в памяти
Все еречисленные в этом проекте репозитории имплементируют интерфейс `IRepository`
- `BookRepository` - репозиторий для работы с сущностями книги
- `LoanRecordRepository` - репозиторий для работы с записями о выдаче книг
- `ReaderRepository` - репозиторий для работы с сущностями читателя

### 3. `Library.Infrastructure.Postgres` - реализация репозиториев для работы с данными, хранящимися в базе данных Postgres
Все перечисленные в этом проекте репозитории имплементируют интерфейс `IRepository`
- `BookRepository` - репозиторий для работы с сущностями книги
- `LoanRecordRepository` - репозиторий для работы с записями о выдаче книг
- `ReaderRepository` - репозиторий для работы с сущностями читателя

- `AppDbContext` - контекст базы данных Postgres
- `DataInitializer` - реализация инициализации данных в базе

### 4. `library.Tests` - Тесты

#### `LibraryFixture`

Создан класс `LibraryFixture`, инициализирцющий набор данных для тестирования, используя репозитории:
- `BookRepository`
- `ReaderRepository`
- `LoanRecordRepository`
 
Сами данные, используемые для тестирования, при этом предопределены в классе `SeedData` в проекте `Library.Domain`.

#### `LibraryTest`
Реализовано 5 unit-тестов с использованием LINQ для проверки бизнес-запросов:

| Тест                               | Описание                                                                                 |
| ---------------------------------- | ---------------------------------------------------------------------------------------- |
| `GetBorrowedBooks`                 | Возвращает список всех выданных книг, упорядоченных по названию.                         |
| `GetMostActiveReadersDuringPeriod` | Находит топ 5 читателей, прочитавших больше всего книг за заданный период.               |
| `GetReadersWithLongetsLoan`        | Определяет читателей,  бравших книги на наибольший период времени, упорядоченных по ФИО. |
| `GetMostPopularPublisher`          | Выводит топ 5 наиболее популярных издательств за последний год.                          |
| `GetLeastPopularPublisher`         | Находит топ 5 наименее популярных издательств за последний год.                          |


### 5. `Library.Application.Contracts` - описание DTO и интерфейсов
#### `DTOs` - описание моделей Data Transfer Object
| DTO                   | Назначение                                                                                     |
| --------------------- | ---------------------------------------------------------------------------------------------- |
| BookCreateDTO         | Создание сущности новой книги в библиотеке                                                     |
| BookGetDTO            | Получение сущности книги из библиотеки                                                         |
| LoanRecordCreateDTO   | Создание записи о выдаче книги                                                                 |
| LoanRecordGetDTO      | Получение записи о выдаче книги                                                                |
| ReaderCreateDTO       | Создание сущности читателя                                                                     |
| ReaderGetDTO          | Получение сущности читателя                                                                    |
| BookLoanCountDTO      | Получение сущности книги с информацией о том, сколько раз она была выдана                      |
| PublisherLoanCountDTO | Получение информации об издателе, включая информацию о том, сколько раз его книги были выданы  |
| ReaderLoanCountDTO    | Получение сущности читателя с информацией о том, сколько раз ему выдавались книги              |
| ReaderLoanDurationDTO | Получение сущности читаля с информацией о том, на какой максимальный срок ему выдывались книги |

#### `Interfaces` - описание интерфейсов для сервисного слоя
- `IApplicationService` - интерфейс с описанием CRUD-операций над сущностями предметной области
- `ILibraryAnalyticsService` - интерфейс с описанием аналитических запросов


### 6. `Library.Application` - сервисный слой
#### `MappingProfile`
Маппер для трансформации сущностей предметной области в DTO и наоборот, использует **AutoMapper**.

#### `Services` - реализация сервисов
Здесь находятся сервисы, имплементирующие интерфейс `IApplicationService` и реализующие CRUD-операции для работы с сущностями предметной области:
- `BookService` - сервис для работы с книгами
- `LoanRecordService` - сервис для работы с записями о выдаче книг
- `ReaderService` - сервис для работы с читателями

А `LibraryAnalyticsService` реализует операции для аналитических запросов, имплементирует интерфейс `ILibraryAnalyticsService`.


### 7. `Library.Api` - Веб-API
Здесь реализованы контроллеры для работы с сервисом:
- `CrudControllerBase` - базовый контроллер для CRUD-операций над сущностями предметной области
- `AnalyticsController` - для аналитических запросов
- `BookController` - для работы с книгами, наследуется от `CrudControllerBase`
- `LoanRecordController` - для работы с записями о выдаче книг, наследуется от `CrudControllerBase`
- `ReaderController` - для работы с читателями, наследуется от `CrudControllerBase`


### 8. `Library.Generator.Kafka` - Генератор тестовых данных для Kafka
- `Services\IProducserService` - интерфейс для отправки сообщений в Кафку
- `Services\GeneratorService` - сервис генерации данных
- `KafkaProducerService` - продюсер Кафки (имплементирует `Services\IProducserService`)
- `LoanRecordGenerator` - генератор записей о выдаче книг
- `Serilizers\KeySerializer` - сериализатор ключей для сообщений Кафки
- `Serilizers\ValueSerializer` - сериализатор значений для сообщений Кафки

### 9. `Library.Infrastructure.Kafka` - Подписчик на данные Kafka
- `KafkaConsumer` - консьюмер Кафки
- `LoanRecordGenerator` - генератор записей о выдаче книг
- `Deserilizers\KeyDeserializer` - десериализатор ключей для сообщений Кафки
- `Deserilizers\ValueDeserializer` - десериализатор значений для сообщений Кафки

### 10. `Library.Client` — реализация клиентского приложения

* `wwwroot` — статические ресурсы клиентского приложения: стили, изображения, `index.html`;
* `Api` — обёртка над API-клиентом, сгенерированным на основе контрактов серверного приложения;
* `Components` — переиспользуемые UI-компоненты (модальные окна, таблицы, гриды) для работы с сущностями библиотеки (книги, читатели, записи о выдаче);
* `Layout` — компоненты основной разметки приложения и навигационного меню, а также связанные с ними стили;
* `Pages` — страницы приложения для просмотра и редактирования сущностей, а также главная страница с аналитическими запросами;
* `_Imports.razor` — общий файл импорта пространств имён и компонентов;
* `App.razor` — корневой компонент приложения, отвечающий за маршрутизацию;
* `Program.cs` — точка входа клиентского Blazor WebAssembly-приложения и конфигурация сервисов.
